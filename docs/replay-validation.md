# 固定轨迹与性能验证

## 40 条轨迹 / 160 个检查点

`fixtures/replay.json` 固定 40 个按时间顺序执行的任务，每个任务包含 4 个查询检查点，合计 160 个。两个项目位于不同目录、使用相同目录名，跨多个会话执行。夹具单独记录原始事件、可重放模型候选、外部期望 ID / 正文 / 版本及禁止召回项。评测答案和检查点不会传入模型，也不写入记忆。

`scripts/evaluate-replay.ts` 通过公开 Memory Service 执行采集、处理、查询、凭据签发与消费、纠正、预览删除、暂停、环境更新、反馈和重启。没有直接修改数据库模拟领域结果。模型替身只按原始事件匹配预置候选，使用确定性向量便于重现；因此本回放检查一致性，不能冒充实际 Qwen 的语义召回或抽取质量。

| 场景 | 任务数 | 检查点数 | 主要检查 |
| --- | ---: | ---: | --- |
| 基础记忆 | 4 | 16 | 中文、英文、代码混合事实，保留否定、数字、例外 |
| 重试 | 4 | 16 | 每源重试 10 次，不增加事件或证据 |
| 明确纠正 | 4 | 16 | 新版本立即生效，纠正前上下文交付被拒，旧正文不再现 |
| 删除 | 4 | 16 | 先预览再提交，物理清理完成，原始来源重放遭拒，重启不复活 |
| 暂停与恢复 | 4 | 16 | 暂停不采集、不召回，恢复不补采期间输入 |
| 不可信偏好 | 4 | 16 | 引用内容和 MCP 模型自述不升级为用户偏好 |
| 环境条件 | 4 | 16 | node/runtime/cache/driver 依赖变化退出默认召回，历史仍可解释 |
| 老化 | 4 | 16 | 经历 181 天后归档；精确历史查询仍能找到 |
| 固定 | 4 | 16 | 固定后豁免时间归档，版本与来源保持可查 |
| 反例 | 4 | 16 | 可信失败来源及反馈使旧经历进入待复核；当前查询排除 |
| **合计** | **40** | **160** | 每条轨迹均检查跨项目隔离与重启后的状态 |

执行：

```sh
npm run evaluate:replay -- --output /tmp/banana-replay-results.json
```

第一次执行发现 4 个历史查询失败：归档经历的精确代码匹配被时间降权后，无关向量候选占据上下文。已修复显式历史查询不做时间降权、精确代码优先，保持原有外部期望不变，再次执行全部通过。实现了正文环境依赖识别后，为第 35 条固定经历显式设置其原文要求的 Node 22 前置环境；固定不覆盖环境失效，原有正例期望保持不变。

这是固定集合的结果，不是对任意输入的保证。`84/84` 只属于确定性模型替身的回放，不能作为 PRD 实际本地模型 Recall@6 ≥90% 的证据；真实模型抽取字段准确率和来源引用质量由独立模型评测报告。

## 性能脚本

`scripts/benchmark.ts` 默认使用 20,000 条事件、5,000 条记忆、两个项目和两个并行会话。全部数据经 `MemoryService.record` 与 `processPending` 创建，不直接写表。计时包括 recall 内的查询 embedding、项目与状态检查、上下文持久化以及受控交付检查。冷模型准备、首次查询与热查询分别报告。

```sh
# 先验证工具链；不是 PRD 数据规模
npm run benchmark -- --events 40 --memories 10 --queries 20

# 默认完整数据规模，使用确定性抽取与 embedding 替身
npm run benchmark -- --output /tmp/banana-benchmark.json

# 完整数据规模；抽取仍为预置候选，文档与查询向量来自固定本地模型
npm run benchmark -- --models-dir /absolute/path/to/model-cache --output /tmp/banana-real-embedding-benchmark.json
```

本次 smoke：40 事件 / 10 记忆 / 20 次双会话查询全部完成，正确命中 20/20，跨项目泄漏 0。最新执行使用字母资源标识以区分独立事实，热查询 p95 97.19 ms，采样 Node RSS 峰值约 186.8 MiB；当时还并行运行另一个完整数据规模的写入测试。这仅验证性能脚本可用，不属于完整数据规模，也不包含真实模型。

实际测试机器为 Apple M4 Pro / 48 GiB，尚未在 16 GiB 目标机测量。脚本报告明确将 `prdPerformanceGate.passed` 标为 false：缺少真实 hook / Claude 适配器开销、Claude 同机运行影响、生成耗时及完整峰值模型内存/下载磁盘测量。Node RSS 使用采样，子进程 RSS 为可取得时的末态快照，数据库磁盘仅在采集后与查询后测量，不混称系统峰值。
