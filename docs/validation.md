# 本地试用版验收记录

范围：实现 `prd.md`，并交付两种本地接入：一个可安装的 Claude Code 插件增强模式，以及前台常驻服务 + 全局 Skill + Streamable HTTP MCP 的标准模式。用户确认：**先交付当前 48 GB Mac 上验证的试用版，16 GB 验证保留为公开发布前门槛**。

测试机器：Apple M4 Pro，48 GiB RAM，macOS 26.5.2；Node 22.23.1；Claude Code 2.1.231；LanceDB OSS Node SDK 0.38.0。模型和 llama.cpp 的固定版本、文件大小、来源与校验和见 `models/manifest.json`。

## 发布前仍需补充的证据

- 在 **Apple Silicon / 16 GB** 机器上使用最终版本、真实查询 embedding、20,000 事件 / 5,000 记忆 / 两并行会话，测量热召回 p95、hook 端到端延迟、峰值资源及与 Claude 同机的影响。
- 40 轨迹回归采用可重放提取夹具；真实模型小样本是另一组 12 事件 / 24 查询。二者不能相互替代，也不保证任意真实项目达到同等准确率。
- “无长期记忆 / 原始经历 / 聚合＋老化”的真实任务成功、重复纠正及资源价值对比尚未实测。当前不声称存在固定成功率提升。
- `banana-memory@0.2.1` 包含本地管理页、模型身份展示和跨项目作用域，并继续通过 GitHub Actions OIDC trusted publishing 发布。
- HTTP 接入已通过 SDK 客户端协议测试，尚未补做真实 Claude Code + HTTP MCP + 全局 Skill 的双会话任务闭环；当前不能用旧插件闭环代替这项证据。

## 测量的解释边界

UTF-8 字节数作为固定且保守的上下文 token 上界，最多六条、800 字节上界。小模型选择原文证据与结构，未实现自由生成的通用总结能力；同义但条件不充分的材料保持候选。天然语言版本依赖只对明确支持的字段作自动硬过滤，其他条件保留原文。

结果验证采用保守的明确单行声明，如“验证通过：具体经历与适用条件”或“验证失败，反例：具体经历与失败证据”。普通描述、引用、否定和问句不会自动授予任务成功；经验晋升仍需至少三个独立任务、两个会话及完整来源。

故障时先保证主任务继续。hook 硬期限为 1,000 ms；未可靠落盘不能确认接收。下次运行恢复队列，但不会补采暂停或宿主超时期间丢失的输入。下载后离线仅指本产品记忆处理，Claude Code 自身仍可能使用远程服务。

删除先拒绝读取再清理，整个原始事件是最小单位；已交付给 Claude 的历史、用户导出和系统备份不在本产品删除范围。数据库优化只清理物理旧快照，业务历史仍作为权威表中的版本化记录保留，直到相应来源删除。
